## 怎么玩（一根手指，局内零故事字）

- 上面是一张敌方攻城机关的零件图纸（像素画），外面绕着一圈黄铜传送带。
- 点下面任意一列，最前面那台**蒸汽连弩车**爬上传送带，绕图一圈，经过每一列 / 每一行时射掉**正对着的、最外面那一格**，颜色对得上才射（每列一发，合体大连弩两发）。
- 子弹打完就冒一团蒸汽消失；转完一圈没打完，回到中间的**机关匣**（等待槽），点它可以再上。
- **机关匣满了还有连弩要回来 = 输**。同色三台进匣**自动合体**成一台大连弩（子弹相加、外圈转齿轮、每列射两发），满了的时候刚好凑成三台也算救回来。
- 传送带同时最多 3 台（正下方的三盏小灯），满了下面几列变暗、点不上去。
- 射掉的地方露出底下的**插画**；清完一关，剩下的蓝图纸从中间烧开，整张插画露出来，收进画册。

## 一局怎么走

开局（第一次有手势动画）→ 点连弩 → 清完：插画刷开 → 过关页（画册 +1、这一页进度、金币、新伙伴；「下一关」一点就开）
输了：0.6 秒后失败页（「差一点！/ 再试一次」、大字「还剩 X%」、进度条）→「再来」一点就开新的一局（连弩顺序重洗，仍保证有解）。

## 关卡：给一张图就出一关

- `js/levels.js` 里一关就是一张 14×14 / 16×16 的字母图（字母 = 颜色，点 = 空）+ 列数、槽数、`fill`（空白填成哪种「图纸底色」）。
- 程序自动：空白填成底色 → 每个字母画成 2×2 小格（像沙画那样细碎）→ 数每种颜色几格 → 拆成 20 / 30 / 40 发的连弩 → 洗进几列 → 机器人试打，打不过就重洗（几毫秒），保证有解。
- 排法：每列前三成「先外层颜色、后里层」，开局顺手；子弹少的小连弩往后排，快清完时还剩好多台、一圈圈回槽，难处在最后一点。
- 新图：用 `tools/image-to-level.html`（在原型文件夹里起个本地服务器打开）拖一张图片进去，自动缩成格子、颜色归到 8 种、配好底色，复制贴进 `levels.js` 就是一关；还会让「像真人的机器人」和「闭眼乱点」各试打 40 遍，告诉你难不难、选择重不重要。

**出图规矩（机器人量出来的，以后每张新图都照这个）**
1. **整张要填满。** 第一版图大片留空，结果「闭眼乱点」也能赢 80–100%：每种颜色从某个方向都露在外面，随便放哪台都打得到，选择不重要 = 不好玩。填满以后乱点只赢 13–45%，会玩的赢 50–80%。底子 Pixel Flow 的图也是满的。
2. **一大块主色、里面嵌几处小细节**（龙头、机关兽）：输都输在最后一点。**一圈套一圈超过两层**（同心齿轮、带边框的盾）：会让人死在中盘。
3. 颜色 3–5 种（不算底色）。
4. 难度像过山车：第 1 关留空、5 格槽送分（教学）；第 3 关留空当喝水关；其余填满，难关 3 格槽、缓一口气的 4–5 格槽。
